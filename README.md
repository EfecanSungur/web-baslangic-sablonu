# Web Başlangıç Şablonu

Sıfırdan web sitesi yapmak isteyenler için **sade, anlaşılır ve mobil uyumlu** bir başlangıç şablonu. Framework yok; yalnızca HTML, CSS ve biraz JavaScript.

**Sıfırdan Web Sitesi** eğitim serisinde bu yapıyı adım adım birlikte kuruyoruz.

## İçinde neler var?
- **Semantik HTML iskeleti:** `header`, `nav`, `main`, `section`, `article`, `footer`
- **Tasarım değişkenleri:** Renkleri ve yazı tipini `css/style.css` dosyasının en üstünden tek yerden değiştirin
- **Mobil uyumlu düzen:** Flexbox ve Grid, `clamp()` ile esnek boyutlar
- **Mobil menü:** Birkaç satır JavaScript ile, erişilebilir (`aria-expanded`)
- **Erişilebilir form:** Her alanda `label`, doğru `type` ve `autocomplete`
- Hareket hassasiyeti olanlar için `prefers-reduced-motion` desteği

## Nasıl kullanılır?
1. Sağ üstteki **"Use this template"** butonuyla kendi kopyanızı oluşturun ya da ZIP olarak indirin.
2. Klasörü VS Code ile açın.
3. **Live Server** eklentisiyle `index.html` dosyasını açın.
4. Metinleri, renkleri ve görselleri kendinize göre değiştirin.

## Dosya yapısı
```
web-baslangic-sablonu/
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
```
